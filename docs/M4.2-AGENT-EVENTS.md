# M4.2 Explicit Agent Events

状态：2026-09-23 完成。

应用构建时复制 `cmux.exe` CLI 到终端程序目录，并把该目录加入子 Shell 的 PATH。每个 Shell 额外获得 `CMUX_WORKSPACE_ID`、`CMUX_PANE_ID`、`CMUX_SESSION_ID` 和 `CMUX_PIPE_NAME`；原环境变量完整保留。终端中执行 `cmux notify working`、`waiting`、`completed` 或 `error`，CLI 通过本机命名管道发送 JSON，应用验证三个 ID 与当前运行 Pane 匹配才更新状态。不读取终端输出推断这些显式状态。

验收：`--event-smoke` 在 CMD 内先后运行 `cmux notify working` 和 `cmux notify waiting`，应用收到 Working → Waiting，退出码 0；错误 Workspace/Pane/Session ID 被拒绝，原 Pane 状态保持不变。构建 0 警告、0 错误。
