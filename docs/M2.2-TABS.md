# M2.2 Tabs

状态：2026-09-23 完成。

每个 Workspace 拥有自己的终端组和当前组。顶部 **+ Group** 创建，点击组标题切换，**Close Group** 关闭整组。每个组可通过 Split 包含多个独立终端；每个终端使用独立的官方 WPF TerminalControl 和 ConptyConnection。隐藏的控件仍留在可视树中，以保留原生屏幕内容。关闭组 / Workspace 时关闭所属进程。旧布局中的 `Terminal N` 标题在恢复时改显示为 `Group N`。

2026-09-24：新安装首次启动、点击 **+ Group** 时，自动用当前选中的 Profile 启动终端；默认选中 PowerShell 7。已保存的空组仍保持空白，避免显式关闭后重开应用又启动 Shell。运行中可以切换 Profile，用于下一个 Group 或 Split。

验收：构建 0 警告、0 错误；`scripts/M2.Workspace-Smoke.ps1` 覆盖 Tab 新建、选择、关闭；`--tab-smoke` 在两个 Workspace 内启动三个 CMD，切换 Tab 和 Workspace 后三个 Shell 仍运行，返回首个 Tab 后 `TAB-ONE` 屏幕仍在，见 `artifacts/m2.2-tab-restore.png`。测试退出码 0、`failures=0`、无 OpenConsole 残留。M1 的 50 次生命周期测试在新结构下继续通过。
