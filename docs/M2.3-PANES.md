# M2.3 Split Pane

状态：2026-09-23 完成。

每个 Group 的 `RootPane` 是 Core 二叉树。点击 Split Right / Split Down 或使用 Alt+D / Alt+Shift+D，当前 Pane 分成两个，新 Pane 用当前选中的 Profile 启动独立 Shell。点击 Pane 或使用 Alt+方向键可聚焦相邻 Pane；Focus Pane 按顺序循环。拖动灰色分隔条改变比例（限制 15%–85%）。Close Terminal 关闭当前 Shell 并让同级 Pane 占据其位置；只有一个 Pane 时保留空 Pane。

2026-09-24 交互修正：每个终端显示独立标题栏及 × 关闭按钮；组标签表示终端组。官方 WPF HwndHost 的 Tab/方向键先由 UI 线程消息过滤器直接送达原生终端窗口，避免 WPF 将 Tab 导航到侧栏。真实窗口测试确认 Tab 后焦点仍为 `HwndTerminalClass`，CMD 能处理 Tab 补全和方向键历史。Ctrl+V 在 WPF 文本框内执行文本框粘贴，在终端内仍发送给 Shell。

显式关闭单个终端时，其持久化启动命令会被清除，重开应用不会复活该终端；空 Pane 仍留在组内。命令面板的 `Close All Terminals` 关闭全部终端并立即保存空布局，Workspace 与 Group 保留。关闭 GUI 则只断开连接，活跃 Shell 按 M5 设计继续运行。

2026-09-24：Split 新 Pane 改为使用当前 Profile 立即启动，即使原 Pane 尚未启动或已关闭也可工作；在 Profile 未指定目录时继承原 Pane 当前目录，默认 Profile 为 PowerShell 7。

布局使用每 Tab 一个 Canvas，已启动的 TerminalControl 始终留在可视树中，避免重挂官方 HwndHost 时丢失屏幕缓冲区。

验收：构建 0 警告、0 错误；`scripts/M2.Workspace-Smoke.ps1` 覆盖 Pane Tree 分割、聚焦、比例、关闭；`--pane-smoke` 启动三个 Pane，调整比例，切换方向焦点，关闭一个 Pane 后剩两个，退出码 0、`failures=0`、无 OpenConsole 残留。截图见 `artifacts/m2.3-split-panes.png`。
