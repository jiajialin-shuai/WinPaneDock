# M4.3 Waiting Notification

状态：2026-09-24，定位流程完成；当前 MSIX 仍使用通知区域 balloon，正式 Windows Toast 待接入。

只有显式事件使非前台 Pane 从 Working 转为 Waiting 时，应用显示系统通知区域提醒，包含 Agent 名称和 Workspace / Group。点击提醒通过 Core FocusManager 切换 Workspace、Group、Pane，并激活终端窗口。当前已打包 WPF 应用仍使用 `NotifyIcon.ShowBalloonTip`；Windows Toast 尚未实现。

验收：`--notification-smoke` 在第二 Pane 前台时给第一 Pane 发送 Working→Waiting，通知计数加一；模拟点击后 FocusPath 回到第一 Pane，退出码 0，无 OpenConsole 残留。
