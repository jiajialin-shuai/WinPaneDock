# M1.2 Terminal Settings

状态：2026-09-23，5/7 项完成。

首次启动生成 `%LOCALAPPDATA%\cmux\terminal-settings.json`；点击右上角设置按钮中的 **Edit terminal settings** 后可修改，重新打开程序生效。字段：`fontFamily`、`fontSize`（4–72）、`cursorStyle`（官方控件的 `BlinkingBlock`、`SteadyBlock`、`BlinkingUnderline`、`SteadyUnderline`、`BlinkingBar`、`SteadyBar`）、`colorScheme`（`Campbell` / `Solarized Dark`）、`padding`（0–64）。M0 的 `--font` 参数仍可临时覆盖字体。

验收：构建 0 警告、0 错误；修改为字号 20、SteadyBlock、Solarized Dark、留白 12 后启动 CMD，实际渲染见 `artifacts/m1.2-solarized-settings.png`。关闭窗口后 OpenConsole 和 CMD 退出。

剩余两项：官方 WPF `TerminalControl.SetTheme` 仅接受字体、字号、主题色与光标；`TerminalContainer` 没有背景透明度或 Scrollback 长度设置接口。其原生 `HwndTerminal::Initialize()` 使用固定的 `_terminal->Create({ 80, 25 }, 9001, *_renderer)`。WPF 顶层窗口透明度会同时淡化文字，也无法让 HwndHost 原生背景单独透明，因此未把这项伪装为背景透明度。要完成 2/7，需要维护自建的 Windows Terminal 原生控件版本及相关设置接口。
