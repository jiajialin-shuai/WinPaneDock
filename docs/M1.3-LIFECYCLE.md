# M1.3 Terminal Lifecycle

状态：2026-09-23 完成。

当前界面首次启动、新建 Group 和 Split 会自动 Start；右上角设置面板保留 **Start / Restart / Close / Kill / Focus**，终端标题栏另有单独关闭按钮。Start 创建 `ConptyConnection`，赋给官方 WPF 控件后启动；Resize 由控件触发连接的 `Resize`，也可显式调用 `TriggerResize`；Close 从控件解绑并清理连接；Kill 立即终止 Shell 后清理；Restart 使用原命令和启动目录创建新连接。

验收命令：

```powershell
dotnet build spikes/M0.Terminal.Wpf/M0.Terminal.Wpf.csproj --no-restore
spikes/M0.Terminal.Wpf/bin/Debug/net8.0-windows/Cmux.Spike.Terminal.exe --lifecycle-smoke 50
Get-Content spikes/M0.Terminal.Wpf/bin/Debug/net8.0-windows/m1-lifecycle-smoke.log
```

本机结果：构建 0 警告、0 错误；50 次循环，包含每第 5 次重启、每第 10 次 Kill，其余 Close，且每次显式 Resize / Focus。`failures=0`，App 退出码 0；句柄数 841 → 878（初次使用的固定开销，在 5 次和 50 次测试后增量基本相同）；结束后无测试产生的 OpenConsole 进程。
