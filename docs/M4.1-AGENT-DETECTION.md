# M4.1 Agent Detection

状态：2026-09-23 完成。

`Cmux.Core.AgentDetector` 用 Windows Toolhelp 快照从 Pane 的 Shell PID 向下遍历进程树。优先按子进程可执行文件名识别 Codex、Claude、Grok、Gemini、OpenCode；若无直接命中，再参考明确的启动命令和完整终端标题。结果包含来源和命中 PID；不读取终端输出文字。`Unknown` 表示未识别 Agent，与任务状态的 `Unknown` 是两个独立字段；未安装状态钩子的 CLI 仍可能显示“status not reported”。

验收：`scripts/M4.AgentDetection-Smoke.ps1` 覆盖五种 Agent、跨进程树隔离与启动命令提示；四 Pane 实景测试得到 `Codex:Codex/ProcessTree`、`Claude:Claude/ProcessTree`，PowerShell / Dev Server 为 `Unknown/None`。本机运行的 `opencode.exe` 位于 WinPaneDock Shell 进程树下，新增规则可以识别。构建 0 警告、0 错误。
