# M4.1 Agent Detection

状态：2026-09-23 完成。

`Cmux.Core.AgentDetector` 用 Windows Toolhelp 快照从 Pane 的 Shell PID 向下遍历进程树。优先按子进程可执行文件名识别 Codex、Claude、Grok、Gemini；若无直接命中，再参考明确的启动命令和完整终端标题。结果包含来源和命中 PID；不读取终端输出文字。
