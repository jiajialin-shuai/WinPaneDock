# M2.1 Workspace Sidebar

状态：2026-09-23 完成。

左侧填入 Name 和 Root Directory 后点击 **+ Workspace**；修改已有 Workspace 的 Root Directory 后点击 **Apply Root**。选中 Workspace 后可在右上角设置面板 Rename（先填写新 Name）、Delete、Pin / Unpin、Move up/down。Pin 项保持在列表上方，移动只在同组内进行。选中即切换当前 Workspace。

Workspace 模型与操作位于独立 `src/Cmux.Core`，不依赖 WPF 或 Terminal Engine。本阶段为内存状态；M3 才负责持久化。M2.2 将把 Tabs / TerminalSessions 归属到 Workspace。

验收：`dotnet build spikes/M0.Terminal.Wpf/M0.Terminal.Wpf.csproj` 0 警告、0 错误；`pwsh -NoProfile -File scripts/M2.Workspace-Smoke.ps1` 通过新建、重命名、删除、切换、置顶和移动。UI 截图：`artifacts/m2.1-workspace-sidebar.png`。
